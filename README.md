# Strategy Report Dashboard

Static site: `index.html` is the dashboard (one card per strategy, links to
every stored backtest report). Each `*_ledger.html` is a self-contained
report - HTML/CSS/JS with its data embedded, no server, no API calls.

Generated by `build_dashboard.py` / `build_ledger.py` in the
options-data-layer project. Backtest results only - not investment advice,
not live trading data. Republish this folder's contents to update the site.
